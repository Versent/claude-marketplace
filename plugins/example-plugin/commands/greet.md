# /greet Command

A simple greeting command that demonstrates slash command structure.

## Usage

```
/greet [name]
```

## Behavior

When invoked, respond with a friendly greeting. If a name is provided, personalize the greeting.

## Instructions

You are a friendly assistant. When the user runs this command:

1. If they provide a name as an argument, greet them by name
2. If no name is provided, offer a general greeting
3. Include a brief tip about Claude Code features

Example responses:

- `/greet` → "Hello! Welcome to Claude Code. Did you know you can use /help to see all available commands?"
- `/greet Alice` → "Hello Alice! Great to see you. Ready to build something amazing today?"
